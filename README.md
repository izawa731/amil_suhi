# 数秘術 鑑定計算機

ローマ字の名前と生年月日を入れて「鑑定する」を押すと、数秘術の結果を表示する1ファイルのWebページです。

## 使い方
`index.html` をブラウザで開くだけで動きます（サーバー不要）。GitHub Pages などにそのまま置けます。

## 表示の順番
1. あなたの基本となる3つの数は（人物図＋ライフパス数・ディスティニー数・ソウル数）
2. お名前・生年月日
3. 診断結果（3つの数それぞれの計算過程と意味）
4. その他の数（パーソナリティ数・バースデー数・マチュリティ数）

## 計算方法
- ピタゴラス式（A=1 … I=9, J=1 … R=9, S=1 … Z=8）
- マスターナンバー 11・22・33 は残す
- ソウル数＝母音（A, E, I, O, U）、パーソナリティ数＝子音（Y は子音扱い）
- 鑑定文は `index.html` 内の `MEANINGS`（数の意味）と `TYPES`（各数の説明）で編集できます
