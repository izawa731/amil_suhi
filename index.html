    のばす音は書きません

    • ゆうこ → YUKO おおの → ONO しょうた → SHOTA
    • パスポートで OH などを使っている方は、その書き方で入力してください。

    小さい「っ」は次の文字を重ねます

    • はっとり → HATTORI きっかわ → KIKKAWA
    • 「っち」は TCH：はっちょう → HATCHO

    「ん」は N（B・M・P の前は M）

    • かんの → KANNO けんじ → KENJI
    • なんば → NAMBA ほんま → HOMMA さんぺい → SAMPEI

    入力の例

    • さとう しょうた → SATO SHOTA
    • いとう じゅんいち → ITO JUNICHI
    • きくち ゆうこ → KIKUCHI YUKO
