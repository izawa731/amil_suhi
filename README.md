# 数秘自動計算

ローマ字の名前と生年月日を入れて「鑑定する」を押すと、数秘の結果を表示する1ファイルのWebページです。
`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## 画面の構成
- 左：Birthday（年・月・日）／Name（ローマ字）／鑑定する
- 右（上から）
  1. あなたの基本となる３つの魂の数字は…（過去数・現在数・未来数）
  2. Name / Birthday
  3. 人物図と P（見た目）・LP（頭）・S（心）・M（将来）・D（体）

## 計算方法
| 数 | 計算 |
|---|---|
| LP（頭）＝現在数 | 生年月日の全桁を足す |
| 過去数 | 生まれた日 |
| 未来数 | 生まれた月日の全桁を足す |
| D（体） | 名前の全文字（A=1…I=9, J=1…R=9, S=1…Z=8）を足す |
| S（心） | 名前の母音（A・E・I・O・U）を足す |
| P（見た目） | 名前の子音（Y は子音）を足す |
| M（将来） | LP＋D |

どれも1桁になるまで各桁を足し、途中で 11・22・33 になったらそこで止めます。

## 文章の編集
各数のキーワードは `index.html` 内の `TEXTS`（P・LP・D・M・S × 1〜9, 11, 22, 33）で書き換えられます。
サイト名・ボタン（「数秘を学ぶ」「セッションに申込む」のリンク先 `href="#"`）・フッターは仮の内容です。
